## Objetivo da atividade

Integrar o robô com o algoritmo de Machine Learning, desenvolvendo uma camada em Python capaz de converter inferências do modelo em comandos de movimentação para o robô.

## Descrição da solução

Nesta etapa foi desenvolvida uma camada de integração entre o sistema de visão computacional/Machine Learning e o controle lógico do robô bombeiro.

O ambiente físico do projeto possui dimensão de 1,5m x 1,5m e é dividido em um grid 4x4, totalizando 16 blocos. Cada bloco representa uma região possível para presença da chama.

O algoritmo de Machine Learning tem como objetivo classificar regiões da imagem como `fire` ou `non_fire`. Após a identificação do bloco com maior probabilidade de fogo, o sistema converte esse bloco em uma coordenada física central e gera um comando para o robô.

## Fluxo da integração

```text
Inferência do Machine Learning
↓
Identificação do bloco com fogo
↓
Conversão do bloco em coordenada física
↓
Geração do comando de movimentação
↓
Envio/registro do comando para o robô
```

## Exemplo de comando gerado

```json
{
  "acao": "ir_para_fogo",
  "fogo_detectado": true,
  "bloco": "B07",
  "x": 0.9375,
  "y": 0.9375,
  "probabilidade": 0.91,
  "latencia_ms": 0.1324
}
```

## Mapeamento dos blocos

O ambiente possui 1,5m x 1,5m. Como o grid é 4x4, cada bloco possui 37,5cm x 37,5cm.

| Bloco | X | Y |
|---|---:|---:|
| B01 | 0.1875 | 1.3125 |
| B06 | 0.5625 | 0.9375 |
